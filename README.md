# ร้านลับริมทาง — 2-Minute Mental Health Experience

งาน assignment สำหรับ **ooca** (โจทย์สมมติ): ประสบการณ์ดิจิทัลที่ทำจบใน ~2 นาที แล้วผู้ใช้ได้ภาพสะท้อนตัวเอง สิ่งเล็กๆ ที่ทำได้ทันที และก้าวต่อไปที่เหมาะสม

## แนวคิด

| | |
|---|---|
| **Problem** | แบบทดสอบความเครียดเดิม (ooca.co/stress-test) ถามตรงเรื่องอาการ ใช้ 4–5 นาที เหมาะกับคนที่ "พร้อมแล้ว" แต่คนที่รู้สึกไม่โอเคและยังไม่พร้อม ไม่อยากเปิดหน้าที่ถามว่า "คุณกำลังเครียดอยู่หรือเปล่า?" |
| **User** | คนทำงานอายุ 22–35 ที่รู้สึก "ไม่ค่อยโอเค" แต่อธิบายไม่ได้ |
| **Approach** | เล่าเรื่องแทนการถามตรง (projective) ร้านเวทมนตร์ที่ปรากฏเฉพาะคนที่แบกอะไรไว้ในใจ งานนี้เป็น **ประตูบานแรก** ที่พาไปยังแบบทดสอบเดิมและการคุยกับนักจิตวิทยา ไม่ได้แข่งกับของเดิม |

## Flow (เลือกจริง 5 ครั้ง)

```
Intro → ฉากเปิด (ฝนตก) → ประตู 1/5 → ชั้นวาง 2/5 → กระจก 3/5 → เจ้าของร้าน 4/5 → ของฝาก 5/5
      → เช็กใจ 1 ข้อ → ห่อของ → ผลลัพธ์ "ของจากร้าน"

ทางแยก A: ประตู "เดินผ่านไป วันนี้ยังไม่ใช่วัน" → กล่องหน้าประตู → ของฝาก → ผลลัพธ์
ทางแยก B: เช็กใจ "หนักมาก จนบางครั้งคิดว่าไม่อยากมีชีวิตอยู่" → หน้าความปลอดภัย → (ดูของต่อได้)
```

## สิ่งที่แต่ละฉากสะท้อน

| ฉาก | สะท้อน | ตัวเลือก |
|---|---|---|
| ประตู | การเข้าหาความช่วยเหลือ | ผลักเข้าเลย / แง้มดู / ยืนมองนาน / เดินผ่าน |
| ชั้นวาง | สิ่งที่แบกอยู่ | ขวดเมฆฝน (อัดแน่น) / เข็มทิศ (สับสน) / นาฬิกาทราย (ถูกเร่ง) / โคมไฟริบหรี่ (หมดแรง) / ขนนก (ใจเบา) |
| กระจก | มุมมองต่อตัวเอง | เหนื่อยกว่าที่คิด / พยายามยิ้ม / ภาพเบลอ / มาไกลกว่าที่คิด |
| เจ้าของร้าน | ความพร้อมจะเล่า | เล่าตรงๆ / "ก็เรื่อยๆ" / อยากเล่าแต่ไม่รู้เริ่มตรงไหน / เปลี่ยนเรื่อง |
| ของฝาก | สิ่งที่ใจต้องการ | ร่ม (อยากมีคนช่วย) / ชาอุ่น (อยากพัก) / จดหมาย (เข้าใจตัวเอง) / แค่ได้แวะ (โอเค) |
| เช็กใจ | ระดับความหนักใจ | ใช้เลือก next step: เบา → ชวนกลับมา, กลาง → แบบทดสอบความเครียด, หนัก → นักจิตวิทยา + 1323 |

ผลลัพธ์เป็น "ภาพสะท้อน" ไม่ใช่คะแนน ทุกความหมายใช้คำว่า **"อาจ"** และผู้ใช้กด "ไม่ค่อยตรงกับฉัน" เพื่อเปลี่ยนของบนการ์ดได้

## ความปลอดภัย

- **ไม่เก็บข้อมูล:** ทุกอย่างอยู่ในหน่วยความจำของหน้าเว็บ ไม่มี backend, cookie หรือ analytics ข้อความที่พิมพ์ในการ์ดจดหมายไม่ถูกบันทึก
- **ไม่ใช่การวินิจฉัย:** แจ้งตั้งแต่หน้าแรกและท้ายผลลัพธ์
- **ทางแยก B:** ถ้าตอบว่าหนักมากจนไม่อยากมีชีวิตอยู่ จะไปหน้าความปลอดภัยทันที มีปุ่มโทร **1323** (สายด่วนสุขภาพจิต ฟรี 24 ชม.), คุยกับนักจิตวิทยา ooca และ **1669** กรณีอยู่ในอันตราย
- ผลลัพธ์ระดับหนักแสดง 1323 ซ้ำอีกครั้ง

## Accessibility

- สีผ่าน WCAG AA: ตัวอักษรเทา `#3F6866`, ปุ่มหลัก `#009688` 19px/600, ตัวเลือก/ลิงก์ `#1868C6`, ปุ่มอันตราย `#C64A46`
- รองรับคีย์บอร์ด (focus ring), `aria-live`, progressbar มี aria, ปิดแอนิเมชันเมื่อเปิด `prefers-reduced-motion`
- Responsive: มือถือเต็มจอ, จอกว้างกว่า 480px แสดงเป็นกรอบมือถือกลางจอ ทดสอบที่ 390px ไม่ล้น

## โครงสร้างไฟล์

```
index.html             หน้าเว็บ
assets/style.css       สไตล์ (โทเคนสีจาก ooca CI)
assets/logic.js        ตรรกะล้วนของ flow (ทางแยก, next step) แยกไว้ให้ทดสอบได้
assets/components.js   คอมโพเนนต์ UI จากดีไซน์ Stitch (TopBar, SceneCard, OptionButton, ItemCard ฯลฯ)
assets/app.js          หน้าจอแต่ละฉากและการเปลี่ยนจอ
assets/mooca-*.png     Mooca 3 ท่าจากไฟล์ CI (hug / happy / sad) วางทับพื้นหลังทุกฉาก
assets/scenes/*.jpg    พื้นหลังฉากจาก Stitch (ไม่มีตัวละคร)
tests/index.html       เทสต์ 19 ข้อ (logic, components, flow จริงใน iframe) เปิดผ่าน static server ที่ /tests/
tests/audit.js         ตัวช่วยตรวจ responsive/a11y ในเบราว์เซอร์
stitch/PROMPTS.md      พรอมต์ที่ใช้สร้างจอใน Stitch
prototype.html      ต้นแบบไฟล์เดียว (ภาพฝังเป็น base64)
figma/build_page.js สคริปต์สร้างหน้า Figma ผ่าน Figma MCP (use_figma)
```

เป็น vanilla HTML/CSS/JS ไม่มี build step เปิดผ่าน static server ใดก็ได้ เช่น `npx serve .` แล้วเปิด `/tests/` เพื่อรันเทสต์ในเบราว์เซอร์

### GitHub Actions (`.github/workflows/ci.yml`)

1. **test** — ทุก push และ pull request: เปิด `tests/index.html` ใน Chromium (Playwright) ให้เทสต์ทั้งหมดต้องผ่าน แล้วตรวจทุกจอที่ 320px และ 414px ว่าไม่ล้นแนวนอน ข้อความไม่ถูกตัด ภาพมี alt และปุ่มมีชื่อ (`scripts/ci-check.mjs`)
2. **deploy** — เฉพาะ push ขึ้น `main` และ test ผ่าน: อัปโหลด `index.html` + `assets/` ขึ้น GitHub Pages

ครั้งแรกต้องเปิด Pages ใน repo: **Settings → Pages → Source: GitHub Actions**

## ตัวชี้วัด (สำหรับนำเสนอ)

| ตัวชี้วัด | บอกอะไร |
|---|---|
| อัตราเล่นจนจบ (intro → ผลลัพธ์) | เรื่องเล่าดึงคนที่ยังไม่พร้อมให้อยู่ได้ 2 นาทีไหม |
| อัตรากดต่อไปแบบทดสอบความเครียด / คุยกับผู้เชี่ยวชาญ | "ประตูบานแรก" พาไปยังบริการเดิมได้จริงไหม (แยกตามระดับเช็กใจ) |
| อัตรากด "ไม่ค่อยตรงกับฉัน" | ความหมายของของแต่ละชิ้นตรงใจแค่ไหน |
| อัตราเก็บ/แชร์การ์ด | ผลลัพธ์มีความหมายพอจะเก็บไว้ไหม |
| อัตรากลับมาเล่นซ้ำ | ร้านกลายเป็นที่แวะประจำไหม |
| สัดส่วนทางแยก A และ B | คนยังไม่พร้อมมีมากแค่ไหน และระบบส่งต่อกรณีเสี่ยงได้ทันไหม |

> ถ้าจะวัดจริง ควรเก็บเฉพาะ event แบบไม่ระบุตัวตน (ไม่เก็บคำตอบรายคน) และแจ้งผู้ใช้ให้ชัด
